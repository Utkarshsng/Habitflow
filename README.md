# HabitFlow

A clean React habit tracker with CRUD, daily completion, streak calculations, analytics, heatmap, dark mode, and localStorage persistence.

## Stack

- React
- JavaScript
- CSS
- Vite
- React Router DOM
- lucide-react
- Browser localStorage
- ESLint
- npm

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Main concepts demonstrated

- Reusable React components
- Context API
- Custom hooks through context
- Controlled forms
- CRUD operations
- Derived analytics from source data
- Date-based streak calculations
- localStorage persistence
- Responsive CSS
- Accessible labels and buttons
- Client-side validation
